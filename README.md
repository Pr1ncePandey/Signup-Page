## Overview

The Signup Page is a basic web page that allows users to sign up by providing their details. It is designed with a clean and responsive layout using HTML and CSS.

## Features

- Responsive design
- Simple and clean layout
- Easy to customize and extend

## Technologies Used

- HTML
- CSS

## Installation

To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Pr1ncePandey/Signup-Page.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Signup-Page
   ```

## Usage

To use the signup page, open the `index.html` file in your web browser. You can also customize the page by editing the HTML and CSS files.
